# 学科大冒险

校园答题 RPG：选择学科迷宫，探索随机地图，遭遇怪物进入答题战斗，击败关底 Boss 通关。支持语文、数学、英语、历史、地理、物理，包含小学、初中、高中三个学习阶段。保留等级、经验、技能和战绩，不含每日任务。

新增独立的 [知识学习版](http://localhost:5173/learn.html)：选择李逍遥、赵灵儿或林月如作为 AI 老师，从知识点或冒险错题开始引导式问答。共用账号，学习记录保存到后端；教学方式、错题引用与数据保留说明见 [学习版说明](docs/learning.md)。

**仓库不包含私人密钥、账号存档、截图，也不包含仙剑原版图片、音乐或游戏文件。** 克隆后可使用纸上冒险和方块世界；仙剑及学习版人物图像需要将有权使用的已提取素材放入 `public/themes/pal/`（目录结构见 [资源配置](docs/themes.md#仙剑资源配置)）。提交范围和各项许可见 [仓库与版权说明](docs/repository.md)。

## 启动

需要 Node.js 22.12+。

```sh
npm install
npm run dev
```

本机打开 http://localhost:5173，其他设备打开 `http://<运行服务的电脑 IP>:5173`。开发服务器同时提供游戏界面和判卷 API。

也可以使用项目根目录的 `./start-web.sh` 和 `./stop-web.sh` 管理后台网页服务。启动日志写入 `.quest-web.log`；首次使用若脚本没有执行权限，运行 `chmod +x start-web.sh stop-web.sh`。

首次进入时输入账号和密码注册，已有账号可以直接登录。无需邮箱、数据库或额外服务。

生产运行：

```sh
npm run build
npm start
```

默认监听 `0.0.0.0:5173`，允许其他设备通过服务器 IP 访问；`npm start` 和 `./start-web.sh` 均可通过 `HOST`、`PORT` 修改监听地址和端口。例如 `PORT=8080 npm start` 使用 8080 端口，`HOST=127.0.0.1 npm start` 限制为仅本机访问。`npm run preview` 也支持远程访问和判卷 API，默认端口为 4173。带 AI 判卷的版本需要 Node 服务，不能只将 `dist/` 放到纯静态托管。

远程设备访问 `http://<服务器 IP>:5173`，知识学习版使用同一地址下的 `/learn.html`。`0.0.0.0` 是监听地址，浏览器中应填写实际 IP。局域网内使用电脑的局域网 IP；跨公网访问还需要公网 IP 或域名、路由器端口转发（如适用），并允许防火墙或云安全组的对应 TCP 端口入站。

已通过脚本启动的服务需执行 `./stop-web.sh && ./start-web.sh` 使修改生效。重启后需要重新登录并重新开始未完成的战斗或迷宫，已保存的账号和进度保留。

## 账号和 JSON 存档

- 个人页显示自己的名字，初始与登录账号一致。“修改名字”保存独立昵称，原登录账号保持可用；“复制全部信息”复制等级、经验、统计、设置和全部已保存战绩（最多 50 条）。浏览器不支持自动复制时会提供可选中的文本。
- 账号信息统一保存在 `data/accounts.json`，首次使用时自动创建。通过服务端环境变量 `QUEST_DATA_FILE` 可以指定其他文件位置。
- 每个账号保存用户名、密码哈希、经验、胜场、正确答题数、最高连击、战绩和游戏设置。等级根据经验计算。
- 注册和登录时，浏览器把密码发送给服务端。服务端使用 Node 内置 `scrypt` 加随机盐计算哈希；登录时使用保存的盐重新计算，并比较哈希。JSON 中的 `passwordHash` 格式为 `scrypt:盐:哈希`，不保存明文密码。
- 登录状态使用 HttpOnly Cookie；退出登录立即删除对应会话。会话最长 7 天，服务器重启后需重新登录，已保存的账号和进度不受影响。
- 战斗血量、判分、技能使用和经验结算由服务端维护；完成战斗后立即写入账号文件，重复提交同一道题不会重复获得经验。未结束的战斗在服务重启后需重新开始。
- JSON 更新采用串行写入和临时文件原子替换。文件无法读取、内容损坏或写入失败时会返回错误，不会用空账号数据覆盖原文件。适用于个人使用的单个 Node 进程，不需要数据库。
- 账号文件已加入 `.gitignore`，且无法通过 HTTP 读取。备份时保留 `data/accounts.json` 即可；手动修改文件前先停止服务，修改后再启动。
- 如果浏览器中存在旧版进度，注册时会出现“导入此浏览器的旧冒险”选项。默认不导入；勾选并成功注册后，旧存档转入新账号，随后删除对应浏览器旧数据。新账号之间不会自动共享旧进度。

## 玩法与设置

- 主界面只保留角色场景、六个学科、学段和难度、开始按钮。背包、记录和设置以弹窗呈现。
- 题型包含选择、填空、简答和开放题；默认混合，也可以在右上角设置中单独选择。
- 选择和填空由服务端规则判分；简答和开放题按理解、内容、理由和逻辑评分。开放题允许不同立场，60 分及以上视为答对。
- 默认不限时。可选每题 5 分钟或 10 分钟轻提醒，时间到了仍可继续作答，不会扣血。判卷等待和弹窗期间暂停提醒计时。
- 答对后随机施展已解锁的攻击或法术，基础伤害 25，3 连击后提升至 35，再加法术及伙伴助战伤害；答错受到敌方攻击或法术。网络或模型服务失败时保留答案、不改变血量，可重试，也可换一道选择题。
- 轻松 / 标准 / 挑战影响数学题复杂度、选项数量、怪物血量、攻击力和胜利经验，不会缩短思考时间。
- 每 100 EXP 升级。计算器开战 20 秒后可用，使用后冷却 45 秒；Lv.2 护盾、Lv.3 灵感每场各可用一次。灵感对选择题排除干扰项，对其他题提供思考方向。
- 进度和偏好设置跟随账号保存在后端，换浏览器或设备登录可继续。客户端不再向 localStorage 写入经验或账号密码。
- 三套独立主题：原生 SVG 手绘、仙剑原版像素素材、Kenney 方块素材；仙剑使用本地原版音乐及战斗音效，其他主题使用独立合成配乐。战斗动作支持攻击、法术和伙伴协同，兼容手机、键盘、减少动画偏好。输入框内打字不会触发 A/B/C/D 快捷答题。
- 等级 1/2/3/5/8 逐步解锁六种招式。首次胜利、累计三次胜利、首次迷宫通关分别获得林月如、赵灵儿和协同奖励卡；后续奖励可升至三星，增加助战概率及伤害。背包可查看详情，卡片保存在账号 JSON。规则和验证方式见 [招式与伙伴卡](docs/combat-cards.md)。

## 界面主题与题库

在右上角“游戏设置”或首页“换个世界”切换纸上冒险、仙剑奇侠、方块世界。仙剑采用原版战斗背景、敌左我右的队伍布局、指令和状态栏；方块主题使用已下载的 Kenney CC0 素材。可定制强调色、减少动画，偏好保存在账号。战斗中切换也保留答案和血量。

战斗采用整屏游戏场景：血条、等级、题目、作答、技能、计算器和战果均留在场景内。支持入场、出招、受击、伤害飘字和倒下动画；长内容在题目面板内滚动，手机横屏采用侧边操作栏。

已导入 **1,740 道 C-Eval 中学选择题**。在“游戏设置 → 题库”选择“C-Eval · 中学学科题库”即可使用，覆盖初高中数学、历史、地理、物理及高中语文，支持公式排版。原有基础题库可继续切换使用。数据来源、许可、过滤清单和重建方式见 [题库说明](docs/question-banks.md)。

每个知识点有稳定的怪物身份，难度提高会改变形态、体型或装备。主题渲染器、交互状态、战斗规则、题库已经分离。扩展说明见 [主题文档](docs/themes.md)，素材来源见 [素材说明](docs/asset-sources.md)。

新增主题可执行 `npm run theme:create -- forest "森林书院"`。生成器创建主题入口和独立 CSS，并更新前后端共用目录；新主题默认继承纸上冒险，可逐项替换场景、地图角色、行走动作、战斗演出和音乐。构建并重启后自动出现在设置中，无需另改账号白名单。

题库独立保存在 `question-banks/`，目前包含 111 道基础题、1,740 道 C-Eval 中学选择题和数学参数化出题。把符合格式的 JSON 放入该目录，重启服务后即可在设置中切换，无需重新构建前端。现有存档自动兼容新偏好字段。

```sh
npm run bank:check -- docs/example-bank.json
```

[题库文档](docs/question-banks.md) 包含格式、替换方式、可运行例子，以及 C-Eval、ScienceQA、GSM8K、CMMU 等公开数据集的规模和接入限制。C-Eval 已导入相关中学子集；其他公开数据集尚未导入。

## DeepSeek 判卷

默认使用官方 `deepseek-v4-flash`，关闭思考模式并使用 JSON 输出。依据 [官方模型说明](https://api-docs.deepseek.com/zh-cn/) 和 [Chat Completions API](https://api-docs.deepseek.com/zh-cn/api/create-chat-completion/) 接入。

将密钥保存在项目根目录的 `deepseek_apikey.txt`，文件只放密钥本身。也可使用服务端环境变量 `DEEPSEEK_API_KEY`；环境变量优先。

- 密钥只由服务端读取，不注入前端、不写入构建产物、不打印到日志。
- 密钥文件和环境文件已加入 `.gitignore`，开发、预览和生产服务均禁止 HTTP 读取密钥与服务端源码。
- 登录后，浏览器通过 `/api/battle/start` 开始战斗，使用战斗 ID 从 `/api/question` 获取题目；参考答案、评分规则由服务端持有。`/api/grade` 根据题目 ID 判分，同一题重复提交会复用结果。
- 简答和开放题提交时，题目、评分要点和学生作答会发送给 DeepSeek；账号和密码不会发给模型。服务端不写入学生作答日志；临时题目和战斗最长保留 24 小时，服务重启后失效，需重新开始战斗。
- 已做账号隔离、同源检查、请求大小限制、频率限制、并发限制、输出字段校验和判卷失败重试处理。

## 验证

```sh
npm test
npm run build
```

单元及 API 测试不调用真实付费接口。

运行 `npm run test:browser` 可自动构建，并在临时端口启动生产服务器和临时账号文件，完成注册、登录、错误密码、存档导入、服务器结算、账号隔离、重启恢复和手机布局测试；需要本机 Google Chrome，不修改正式账号文件，默认不调用付费接口。截图保存在 `artifacts/`。

新增 `npm run test:themes` 验证三主题切换、账号偏好持久化、知识点和难度外观、桌面/手机战斗、输入保留、图片加载与题库私有性，同样只使用临时账号。

如需同时验证登录后的真实 Flash 判卷，使用 `QUEST_LIVE_AI=1 npm run test:browser`；该模式需要有效密钥，并产生一次真实判卷调用。

## 代码位置

- `src/main.js`：状态、接口请求与交互；`src/ui/views.js`：界面与弹窗。
- `src/themes/`：主题注册、独立场景、战斗布局、知识点怪物和样式。
- `src/game.js`：学科元信息、战斗与经验规则，不再包含题库。
- `question-banks/starter.json`、`ceval-school.json`：独立基础题库与 C-Eval 中学题库。
- `server/banks/`：题库格式校验、加载和数学参数化出题。
- `server/questions.js`：题目选择、衍生题型与客观判分。
- `server/deepseek.js`：模型请求与结果校验。
- `server/api.js`：题目会话和 HTTP API。
- `server/accounts.js`：注册登录、密码哈希和 JSON 存档。
- `src/art.js` / `src/audio.js`：角色插画与声音。

题库为演示内容，按学习阶段宽泛分层，尚未按具体年级和教材版本编排。

`npm run test:ceval` 使用临时账号验证 C-Eval 切换、覆盖范围限制、三种风格的公式显示、手机布局、服务端判分和经验保存。

## 随机迷宫冒险

首页“进入迷宫”开启探险；“单场练习”保留原有独立答题战斗。每个学科有一座独立迷宫：语文「墨香书林」、数学「玄机数阵」、英语「符文回廊」、历史「时光古陵」、地理「山海秘境」、物理「灵能机关城」。题库覆盖范围仍生效，例如 C-Eval 没有英语和小学子集。

- 使用方向键、WASD 或手机方向按钮移动，也可以点击已探索的道路自动行走。小地图显示探索范围及关底方向。
- 每次进入生成新地图、守卫位置、知识点、形象变体和灵泉位置。所有道路连通，Boss 在距离入口最远的可达位置。
- 碰到怪物进入原有战斗场景。普通守卫围绕指定知识点出题；题量很少的知识点相应降低守卫血量。Boss 综合考查当前学科，血量约为普通练习的 1.7 倍。
- 胜利后怪物消失，角色走到怪物所在格，恢复 25 点体力。两个灵泉各能将体力恢复到 100 一次。体力在本次探索中延续。
- 只有击败 Boss 才通关；Boss 战经验为对应难度的双倍，通关次数写入账号 JSON。失败保留已经获得的经验；战斗中撤退回到迷宫，当前怪物保留，再次接触重新战斗。
- 页面刷新后通过服务端恢复当前迷宫和战斗。迷宫状态保存在服务进程内，最长 24 小时；服务重启需开始新迷宫，账号经验和通关记录永久保存。

`server/dungeons.js` 负责地图生成、移动和通关规则；`src/ui/dungeon.js` 与 `src/themes/dungeon.css` 负责探索地图、迷雾、小地图、移动动画、相机和三种主题。`/api/dungeon/start / move / continue / leave` 在服务端检查账号归属、墙体、移动序号、遭遇状态和结算，`GET /api/dungeon/current` 用于恢复。

`npm run test:dungeon` 使用临时账号验证三主题探索、桌面与手机布局、刷新恢复、撤退、普通怪战后返回、Boss 通关以及地图重新随机化；`npm test` 另外验证多份地图连通性、怪物与灵泉可达性、移动幂等、账号隔离和通关奖励只结算一次。
