# 知识学习版

访问 `/learn.html` 或在冒险营地点击“进入学堂”。学习版有自己的页面、教学流程和对话记录，共用账号、服务与题库。不会因聊天改变战斗血量或经验。

可选择李逍遥（类比与尝试）、赵灵儿（细分步骤）、林月如（追问与变式）。先选择学科、学段并输入知识点，也可选择一道错题。老师先了解原始思路，再确认具体误解，给提示、解释和变式练习。对话可以随时停止并从“学习记录”继续。

冒险中答错的题在判卷时保存；反馈区的“请老师带我弄懂这道题”会在新标签页打开学堂，并引用原题、选项、学生答案和参考思路。旧版本没有记录具体题目，因此不能还原历史战绩中的错题。题库更换后，已保存的错题仍可学习。

使用服务端 `server/tutor.js` 调用现有 DeepSeek Flash，密钥仍从 `deepseek_apikey.txt` 或 `DEEPSEEK_API_KEY` 读取，不发给浏览器。模型会接收本次知识点、学段、引用题与本次对话内容。账号中的姓名、密码和其他课程对话不随请求发送。

老师正文使用普通文本和 [DeepSeek 流式输出](https://api-docs.deepseek.com/api/create-chat-completion/)，生成的文字通过 SSE 立即送到浏览器。正文不再要求包含 JSON 教学字段，避免格式和辅助字段校验导致整段回答作废。仅在没有正文时自动重试一次，总计最多等待 90 秒。真正断流时保留学生输入，并可展开查看已收到但尚未保存的文字；点击“重试这次回复”即可重试。如果只是模型达到输出长度上限，会保存已收到的内容并提示继续讲。

续聊时使用本次完整师生对话（最多 40 轮），不再依赖模型生成的 JSON 总结。学习记录的提示取自老师最后提出的问题；页面不自动宣称学生已经掌握。旧版记录仍可直接继续。

老师人物位于对话区右上角。开始前及对话中可选择中文、English 或中英对照，对话中的语言选择从下一条回复生效并随成功回复保存。语言选择与学科学段独立。

可选系统语音朗读，默认关闭。可开启自动朗读、手动朗读最新回复、切换设备声音或停止朗读；换课、发送新消息、退出或切到后台会停止当前朗读。自动朗读在本轮完整回复收到后开始，文本仍逐段流式显示。声音来自浏览器/系统安装的语音，不是游戏人物的原声，具体可用声音因设备而异。不支持语音的浏览器仍可正常使用文字学习。

记录存入现有账号 JSON 的 `learningSessions` 和 `mistakes` 字段。旧账号自动兼容，保留最近 12 次学习、100 道错题，每次最多 40 轮学生问答。重启服务后重新登录即可恢复。一次完整师生问答作为一次原子写入，失败不保存半轮，浏览器保留输入；请求编号用于重试去重，版本号阻止多标签页覆盖。

扩展位置：`src/learning/teachers.js` 定义人物与风格；`src/learning/languages.js` 定义教学语言；`src/learning/narrator.js` 管理可选语音；`server/learning.js` 管理学习会话；`server/tutor.js` 管理教学提示和模型流；`src/stream-events.js` 解析网络分块。人物素材沿用本地仙剑资源。`npm run test:learning` 检查 Chrome 与 Firefox 的学习流程、流式显示、语言保存和朗读控制。
